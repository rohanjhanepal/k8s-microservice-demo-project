# Submission folder

| Path | Purpose |
|------|---------|
| `report/` | Written report (PDF/DOCX) if required by the subject |
| `presentation/` | Slides or speaking notes for oral demo |
| `final-zip/` | `ZIP-CONTENTS.md`, `prepare-final-zip.ps1`, and generated export/ZIP |

See **`final-zip/ZIP-CONTENTS.md`** for what belongs in the final ZIP.
