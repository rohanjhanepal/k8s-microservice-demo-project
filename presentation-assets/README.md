# Presentation assets

| Folder | Use |
|--------|-----|
| `screenshots/` | Screen captures from kubectl and browser (rename descriptively) |
| `diagrams/` | Architecture or submission diagrams (export PNG/PDF) |
| `commands/` | **demo-runbook.md** (recording script), **demo-checklist.md** |
| `notes/` | Speaker notes or assessment reminders |

Point your report/presentation to these paths so the ZIP is self-explanatory.
